## 产品验收追踪

| 业务编号 | 核对内容 | 证据 |
| --- | --- | --- |
| A01 | 同群交叉规格查询与公开引用隔离 | WP01、WP02 |
| A02 | 非触发消息、澄清、条件式与明确人工请求 | WP01、真实模型中文样例 |
| A03 | 未绑定可问公开知识，私密订单需归属且对第三方订单统一文案 | WP02 |
| A04 | 有效资料、旧活动、规则冲突、实时失败、图片不可读时补充型号 | WP01、WP02、WP03、WP04 |
| A05 | 私密导购使用本人偏好，更正删除生效，代购条件隔离 | WP03 |
| A06 | 候选与明确订阅分开，退订后取消，规范补货事件重投 | WP03、WP04 |
| A07 | 报名、打卡、问卷去重以及暂停、结束和参与统计 | WP03 |
| A08 | 审批名单与实时资格、活动变更、结果核实、欢迎和关怀过滤历史事件 | WP04、已部署写入验证 |
| A09 | 一人待办、通知失败、连续追问、运营登记与交回 | WP01 |
| A10 | 群证据、投诉与咨询区分、知识发布及旧引用 | WP03、Edge 走查 |
| A11 | 暂停、恢复、过期与订阅取消，公开问答和独立商家查询分支 | WP01、WP02、WP04 |
| A12 | 解绑与退群影响查询、筛选和待发送，重投不恢复删除记忆 | WP02、WP03、WP04 |

测试以可观察的业务结果和接口状态为主。真实消息回执、商家回调认证、邮件实际投递及生产数据均需要相应的接入授权。服务访问与部署步骤见 [服务器部署](DEPLOYMENT.md)。
